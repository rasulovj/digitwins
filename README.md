# DigiTwins | Deep Tech & Digital Twin Group

DigiTwins unites physical industrial zones, manufacturing factory automation, and immersive educational simulations into a single deep tech architecture:

- **DigiTwins Industry:** Special economic zones, GIS spatial land allocation, utility infrastructure telemetry (built upon **Fabriq Land** operations).
- **DigiTwins Factory:** Turnkey manufacturing facility digital twin, IIoT equipment monitoring, OEE analytics, predictive maintenance (built upon **Fabriq Build & Tech** engineering).
- **DigiTwins Education:** VR/AR industrial safety simulators, EdTech serious games transfer, real-time competency analytics (built upon **Xapp** technologies).

## Tech Stack
- **Framework:** Vite 6 + React 19 + TypeScript
- **Styling:** Tailwind CSS v4 (architectural minimal design system)
- **Icons:** Lucide React
- **Languages:** Uzbek (`uz`), Turkish (`tr`), English (`en`)

## Running Locally
```bash
npm install
npm run dev
```
